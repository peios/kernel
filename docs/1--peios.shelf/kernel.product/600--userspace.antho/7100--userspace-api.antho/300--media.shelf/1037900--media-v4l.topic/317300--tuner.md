## Tuners

Video input devices can have one or more tuners demodulating a RF signal. Each tuner is associated with one or more video inputs, depending on the number of RF connectors on the tuner. The `type` field of the respective struct `v4l2_input` returned by the [ioctl VIDIOC_ENUMINPUT](<~kernel/userspace/userspace-api/media-v4l/vidioc-enuminput#rst-vidioc-enuminput>) ioctl is set to `V4L2_INPUT_TYPE_TUNER` and its `tuner` field contains the index number of the tuner.

Radio input devices have exactly one tuner with index zero, no video inputs.

To query and change tuner properties applications use the [VIDIOC_G_TUNER](<https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/Documentation/userspace-api/media/v4l/vidioc-g-tuner.rst?id=9021cc14f7d98b4a1d2c932f52c5343d4d0f6b92>) and [VIDIOC_S_TUNER](<https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/Documentation/userspace-api/media/v4l/vidioc-g-tuner.rst?id=9021cc14f7d98b4a1d2c932f52c5343d4d0f6b92>) ioctls, respectively. The struct `v4l2_tuner` returned by [VIDIOC_G_TUNER](<https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/Documentation/userspace-api/media/v4l/vidioc-g-tuner.rst?id=9021cc14f7d98b4a1d2c932f52c5343d4d0f6b92>) also contains signal status information applicable when the tuner of the current video or radio input is queried.

> [!NOTE]
>
> [VIDIOC_S_TUNER](<https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/Documentation/userspace-api/media/v4l/vidioc-g-tuner.rst?id=9021cc14f7d98b4a1d2c932f52c5343d4d0f6b92>) does not switch the current tuner, when there is more than one. The tuner is solely determined by the current video input. Drivers must support both ioctls and set the `V4L2_CAP_TUNER` flag in the struct `v4l2_capability` returned by the [ioctl VIDIOC_QUERYCAP](<~kernel/userspace/userspace-api/media-v4l/vidioc-querycap#rst-vidioc-querycap>) ioctl when the device has one or more tuners.

<a id="rst-modulators"></a>

## Modulators

Video output devices can have one or more modulators, that modulate a video signal for radiation or connection to the antenna input of a TV set or video recorder. Each modulator is associated with one or more video outputs, depending on the number of RF connectors on the modulator. The `type` field of the respective struct `v4l2_output` returned by the [ioctl VIDIOC_ENUMOUTPUT](<~kernel/userspace/userspace-api/media-v4l/vidioc-enumoutput#rst-vidioc-enumoutput>) ioctl is set to `V4L2_OUTPUT_TYPE_MODULATOR` and its `modulator` field contains the index number of the modulator.

Radio output devices have exactly one modulator with index zero, no video outputs.

A video or radio device cannot support both a tuner and a modulator. Two separate device nodes will have to be used for such hardware, one that supports the tuner functionality and one that supports the modulator functionality. The reason is a limitation with the [VIDIOC_S_FREQUENCY](<~kernel/userspace/userspace-api/media-v4l/vidioc-g-frequency#rst-vidioc-g-frequency>) ioctl where you cannot specify whether the frequency is for a tuner or a modulator.

To query and change modulator properties applications use the [VIDIOC_G_MODULATOR](<~kernel/userspace/userspace-api/media-v4l/vidioc-g-modulator#rst-vidioc-g-modulator>) and [VIDIOC_S_MODULATOR](<~kernel/userspace/userspace-api/media-v4l/vidioc-g-modulator#rst-vidioc-g-modulator>) ioctl. Note that [VIDIOC_S_MODULATOR](<~kernel/userspace/userspace-api/media-v4l/vidioc-g-modulator#rst-vidioc-g-modulator>) does not switch the current modulator, when there is more than one at all. The modulator is solely determined by the current video output. Drivers must support both ioctls and set the `V4L2_CAP_MODULATOR` flag in the struct `v4l2_capability` returned by the [ioctl VIDIOC_QUERYCAP](<~kernel/userspace/userspace-api/media-v4l/vidioc-querycap#rst-vidioc-querycap>) ioctl when the device has one or more modulators.

<a id="rst-radio-frequency"></a>

## Radio Frequency

To get and set the tuner or modulator radio frequency applications use the [VIDIOC_G_FREQUENCY](<~kernel/userspace/userspace-api/media-v4l/vidioc-g-frequency#rst-vidioc-g-frequency>) and [VIDIOC_S_FREQUENCY](<~kernel/userspace/userspace-api/media-v4l/vidioc-g-frequency#rst-vidioc-g-frequency>) ioctl which both take a pointer to a struct `v4l2_frequency`. These ioctls are used for TV and radio devices alike. Drivers must support both ioctls when the tuner or modulator ioctls are supported, or when the device is a radio device.
