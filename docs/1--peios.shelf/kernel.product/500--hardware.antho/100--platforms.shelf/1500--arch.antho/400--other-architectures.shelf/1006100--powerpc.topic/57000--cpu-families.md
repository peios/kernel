This document tries to summarise some of the different cpu families that exist and are supported by arch/powerpc.

<a id="rst-book3s-aka-spapr"></a>

## Book3S (aka sPAPR)

- Hash MMU (except 603 and e300)

- Radix MMU (POWER9 and later)

- Software loaded TLB (603 and e300)

- Selectable Software loaded TLB in addition to hash MMU (755, 7450, e600)

- Mix of 32 &amp; 64 bit:

- All 32 bit:



  ```text
  +--------------+
  |     440      |
  +--------------+
         |
         |
         v
  +--------------+     +----------------+
  |     450      | --> |      BG/P      |

         |
         |

  +--------------+
  ```

## Motorola/Freescale 8xx

- Software loaded with hardware assist.

- All 32 bit:



  ```text
  +-------------+
  | MPC8xx Core |
  +-------------+
  ```

<a id="rst-freescale-booke"></a>

## Freescale BookE

- Software loaded TLB.

- e6500 adds HW loaded indirect TLB entries.

- Mix of 32 &amp; 64 bit:



  ```text
  +--------------+
  |     e200     |
  +--------------+


  +--------------------------------+
  |              e500              |
  +--------------------------------+
                  |
                  |
                  v
  +--------------------------------+
  |             e500v2             |
  +--------------------------------+
                  |
                  |
                  v
  +--------------------------------+
  |        e500mc (Book3e)         |
  +--------------------------------+
                  |
                  |
                  v
  +--------------------------------+
  |          e5500 (64 bit)        |
  +--------------------------------+
                  |
                  |
                  v
  +--------------------------------+
  | e6500 (HW TLB) (Multithreaded) |
  +--------------------------------+
  ```

<a id="rst-ibm-a2-core"></a>

## IBM A2 core

- Book3E, software loaded TLB + HW loaded indirect TLB entries.

- 64 bit:



  ```text
  +--------------+     +----------------+
  |   A2 core    | --> |      WSP       |
  +--------------+     +----------------+
          |
          |
          v
  +--------------+
  |     BG/Q     |
  +--------------+
  ```
