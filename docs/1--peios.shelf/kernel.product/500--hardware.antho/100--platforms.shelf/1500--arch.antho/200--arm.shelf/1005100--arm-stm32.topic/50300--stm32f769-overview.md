## Introduction

The STM32F769 is a Cortex-M7 MCU aimed at various applications. It features:

- Cortex-M7 core running up to @216MHz

- 2MB internal flash, 512KBytes internal RAM (+4KB of backup SRAM)

- FMC controller to connect SDRAM, NOR and NAND memories

- Dual mode QSPI

- SD/MMC/SDIO support\*2

- Ethernet controller

- USB OTFG FS &amp; HS controllers

- I2C\*4, SPI\*6, CAN\*3 buses support

- Several 16 &amp; 32 bits general purpose timers

- Serial Audio interface\*2

- LCD controller

- HDMI-CEC

- DSI

- SPDIFRX

- MDIO salave interface
