---
title: "Reboot property to control system reboot on PPC4xx systems:"
type: reference
description: "Device-tree binding reference for Reboot property to control system reboot on PPC4xx systems:."
---

By setting "reset\_type" to one of the following values, the default
software reset mechanism may be overridden. Here the possible values of
"reset\_type":

```text
      1 - PPC4xx core reset
      2 - PPC4xx chip reset
      3 - PPC4xx system reset (default)
```

## Example:

```dts
		cpu@0 {
			device_type = "cpu";
			model = "PowerPC,440SPe";
			...
			reset-type = <2>;	/* Use chip-reset */
		};
```
