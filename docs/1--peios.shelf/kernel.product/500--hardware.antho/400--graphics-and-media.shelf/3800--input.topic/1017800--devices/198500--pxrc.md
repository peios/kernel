**Author:** Marcus Folkesson &lt;[marcus.folkesson@gmail.com](<mailto:marcus.folkesson@gmail.com>)&gt;

This driver let you use your own RC controller plugged into the adapter that comes with PhoenixRC or other compatible adapters.

The adapter supports 7 analog channels and 1 digital input switch.

<a id="rst-notes"></a>

## Notes

Many RC controllers is able to configure which stick goes to which channel. This is also configurable in most simulators, so a matching is not necessary.

<a id="rst-manual-testing"></a>

## Manual Testing

To test this driver's functionality you may use `input-event` which is part of the `input layer utilities` suite <a id="rst-footnote-reference-1"></a>[1](#rst-footnote-1).

For example:



```text
> modprobe pxrc
> input-events <devnr>
```

To print all input events from input `devnr`.
