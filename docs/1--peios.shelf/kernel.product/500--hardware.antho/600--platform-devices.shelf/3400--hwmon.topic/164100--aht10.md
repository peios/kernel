<a id="rst-description"></a>

## Description

The AHT10/AHT20 is a Temperature and Humidity sensor

The address of this i2c device may only be 0x38

<a id="rst-special-features"></a>

## Special Features

AHT20, DHT20 has additional CRC8 support which is sent as the last byte of the sensor values.

<a id="rst-usage-notes"></a>

## Usage Notes

This driver does not probe for AHT10/ATH20 devices, as there is no reliable way to determine if an i2c chip is or isn't an AHT10/AHT20. The device has to be instantiated explicitly with the address 0x38. See [Documentation/i2c/instantiating-devices.rst](~kernel/hardware/i2c/instantiating-devices) for details.
