## Description

The Vicor PLI1209BC is an isolated digital power system supervisor that provides a communication interface between a host processor and one Bus Converter Module (BCM). The PLI communicates with a system controller via a PMBus compatible interface over an isolated UART interface. Through the PLI, the host processor can configure, set protection limits, and monitor the BCM.
