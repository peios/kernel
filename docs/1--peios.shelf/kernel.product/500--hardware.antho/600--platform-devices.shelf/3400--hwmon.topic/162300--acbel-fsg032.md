<a id="rst-kernel-driver-acbel-fsg032"></a>

Supported chips:

> - ACBEL FSG032-00xG power supply.

Author: Lakshmi Yadlapati &lt;[lakshmiy@us.ibm.com](<mailto:lakshmiy@us.ibm.com>)&gt;

<a id="rst-description"></a>

## Description

This driver supports ACBEL FSG032-00xG Power Supply. This driver is a client to the core PMBus driver.

<a id="rst-usage-notes"></a>

## Usage Notes

This driver does not auto-detect devices. You will have to instantiate the devices explicitly. Please see [Documentation/i2c/instantiating-devices.rst](~kernel/hardware/i2c/instantiating-devices) for details.
