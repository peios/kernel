<a id="rst-description"></a>

## Description

This driver supports hardware monitoring for Analog Devices ADM1177 Hot-Swap Controller and Digital Power Monitors with Soft Start Pin.

<a id="rst-usage-notes"></a>

## Usage Notes

This driver does not auto-detect devices. You will have to instantiate the devices explicitly. Please see [Documentation/i2c/instantiating-devices.rst](~kernel/hardware/i2c/instantiating-devices) for details.

<a id="rst-sysfs-entries"></a>

## Sysfs entries

The following attributes are supported. Current maximum attribute is read-write, all other attributes are read-only.

in0_input               Measured voltage in millivolts.

curr1_input             Measured current in milliamperes. curr1_max               Overcurrent shutdown threshold in milliamperes.
