## List available monitors

<!-- SPDX-License-Identifier: GPL-2.0 -->

**Manual section:** 1

<a id="rst-synopsis"></a>

## SYNOPSIS

**rv mon** \[*-h*\] **monitor_name** \[*-h*\] \[*MONITOR OPTIONS*\]

<a id="rst-description"></a>

## DESCRIPTION

The **rv mon** command runs the monitor named *monitor_name*. Each monitor has its own set of options. The **rv list** command shows all available monitors.

<a id="rst-options"></a>

## OPTIONS

**-h**, **--help**

> Print help menu.

<a id="rst-available-monitors"></a>

## AVAILABLE MONITORS

The **rv** tool provides the interface for a set of monitors. Use the **rv list** command to list all available monitors.

Each monitor has its own set of options. See man **rv-mon**-*monitor_name* for details about each specific monitor. Also, running **rv mon** **monitor_name** **-h** display the help menu with the available options.
