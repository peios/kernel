<a id="rst-description"></a>

## Description

LT7182S is a Dual Channel 6A, 20V PolyPhase Step-Down Silent Switcher with Digital Power System Management support.

<a id="rst-usage-notes"></a>

## Usage Notes

This driver does not probe for PMBus devices. You will have to instantiate devices explicitly.

Example: the following commands will load the driver for a LT7182S at address 0x4f on I2C bus \#4:



```text
# modprobe lt7182s
# echo lt7182s 0x4f > /sys/bus/i2c/devices/i2c-4/new_device
```

It can also be instantiated by declaring an entry in device tree.
