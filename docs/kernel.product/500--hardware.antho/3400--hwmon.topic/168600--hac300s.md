## Description

This driver supports the HiTRON HAC300S PSU. It is a Universal AC input harmonic correction AC-DC hot-swappable CompactPCI Serial Dual output (with 5V standby) 312 Watts active current sharing switching power supply.

The device has an input of 90-264VAC and 2 nominal output voltaged at 12V and 5V which they can supplu up to 25A and 2.5A respectively.
