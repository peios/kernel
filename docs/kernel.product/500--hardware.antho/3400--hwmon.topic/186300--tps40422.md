<a id="rst-description"></a>

## Description

This driver supports TI TPS40422 Dual-Output or Two-Phase Synchronous Buck Controller with PMBus

The driver is a client driver to the core PMBus driver. Please see [Documentation/hwmon/pmbus.rst](~kernel/hardware/hwmon/pmbus) for details on PMBus client drivers.

<a id="rst-usage-notes"></a>

## Usage Notes

This driver does not auto-detect devices. You will have to instantiate the devices explicitly. Please see [Documentation/i2c/instantiating-devices.rst](~kernel/hardware/i2c/instantiating-devices) for details.

<a id="rst-platform-data-support"></a>

## Platform data support

The driver supports standard PMBus driver platform data.
