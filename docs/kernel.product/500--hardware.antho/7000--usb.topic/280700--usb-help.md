For USB help other than the readme files that are located in `Documentation/usb/*`, see the following:

- Linux-USB project:  [http://www.linux-usb.org](<http://www.linux-usb.org>) mirrors at          [http://usb.in.tum.de/linux-usb/](<http://usb.in.tum.de/linux-usb/>) and                 [http://it.linux-usb.org](<http://it.linux-usb.org>)

- Linux USB Guide:    [http://linux-usb.sourceforge.net](<http://linux-usb.sourceforge.net>)

- Linux-USB device overview (working devices and drivers): [http://www.qbik.ch/usb/devices/](<http://www.qbik.ch/usb/devices/>)

The Linux-USB mailing list is at [linux-usb@vger.kernel.org](<mailto:linux-usb@vger.kernel.org>)
