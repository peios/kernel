title: "Analog Devices SSM4567 audio amplifier"
type: reference
description: "Device-tree binding reference for Analog Devices SSM4567 audio amplifier."
---

This device supports I2C only.

## Required properties:

- compatible : Must be "adi,ssm4567"
- reg : the I2C address of the device. This will either be 0x34 (LR\_SEL/ADDR connected to AGND),
  0x35 (LR\_SEL/ADDR connected to IOVDD) or 0x36 (LR\_SEL/ADDR open).

## Example:

```dts
	ssm4567: ssm4567@34 {
		compatible = "adi,ssm4567";
		reg = <0x34>;
	};
```
