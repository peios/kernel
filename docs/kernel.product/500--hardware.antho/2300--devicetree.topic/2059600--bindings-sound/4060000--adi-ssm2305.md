## Required properties:

- compatible : "adi,ssm2305"
- shutdown-gpios : The gpio connected to the shutdown pin.
  The gpio signal is ACTIVE\_LOW.

## Example:

```dts
ssm2305: analog-amplifier {
	compatible = "adi,ssm2305";
	shutdown-gpios = <&gpio3 20 GPIO_ACTIVE_LOW>;
};
```
