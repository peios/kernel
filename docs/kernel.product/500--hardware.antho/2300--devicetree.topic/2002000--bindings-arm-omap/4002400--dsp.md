TI DSP included in OMAP SoC

## Required properties:

- compatible : Should be "ti,omap3-c64" for OMAP3 &amp; 4
- ti,hwmods: "dsp"

## Examples:

```dts
dsp {
    compatible = "ti,omap3-c64";
    ti,hwmods = "dsp";
};
```
