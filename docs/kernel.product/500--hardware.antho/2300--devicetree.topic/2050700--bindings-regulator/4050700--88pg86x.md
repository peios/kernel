## Required properties:

- compatible: one of "marvell,88pg867", "marvell,88pg868";
- reg: I2C slave address.

Optional subnodes for regulators: "buck1", "buck2", using common regulator
bindings given in &lt;[Documentation/devicetree/bindings/regulator/regulator.txt](<~kernel/hardware/devicetree/bindings-regulator/regulator>)&gt;.

## Example:

```dts
	pg868@19 {
		compatible = "marvell,88pg868";
		reg = <0x19>;

		vcpu: buck1 {
			regulator-boot-on;
			regulator-always-on;
			regulator-min-microvolt = <1000000>;
			regulator-max-microvolt = <1350000>;
		};
	};
```
