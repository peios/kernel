## Required properties:

- compatible: "mps,mp8859";
- reg: I2C slave address.

Optional subnode for regulator: "mp8859\_dcdc", using common regulator
bindings given in &lt;[Documentation/devicetree/bindings/regulator/regulator.txt](<~kernel/hardware/devicetree/bindings-regulator/regulator>)&gt;.

## Example:

```dts
	mp8859: regulator@66 {
		compatible = "mps,mp8859";
		reg = <0x66>;
		dc_12v: mp8859_dcdc {
			regulator-name = "dc_12v";
			regulator-min-microvolt = <12000000>;
			regulator-max-microvolt = <12000000>;
			regulator-boot-on;
			regulator-always-on;
		};
	};
```
