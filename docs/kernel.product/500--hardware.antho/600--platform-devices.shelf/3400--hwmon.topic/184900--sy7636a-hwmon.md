Supported chips:

> - Silergy SY7636A PMIC

<a id="rst-description"></a>

## Description

This driver adds hardware temperature reading support for the Silergy SY7636A PMIC.

The following sensors are supported

> - - **Temperature**
>
>     - Temperature of external NTC in milli-degree C

<a id="rst-sysfs-interface"></a>

## sysfs-Interface

- **temp0_input**

  - Temperature of external NTC (milli-degree C)
