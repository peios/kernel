<a id="rst-description"></a>

## Description

IR38x6x are a Single-input Voltage, Synchronous Buck Regulator, DC-DC Converter.

<a id="rst-usage-notes"></a>

## Usage Notes

This driver does not probe for PMBus devices. You will have to instantiate devices explicitly.
