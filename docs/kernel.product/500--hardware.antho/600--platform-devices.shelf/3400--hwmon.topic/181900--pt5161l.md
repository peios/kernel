>

>

Authors: Cosmo Chou &lt;[cosmo.chou@quantatw.com](<mailto:cosmo.chou@quantatw.com>)&gt;

<a id="rst-description"></a>

## Description

This driver implements support for temperature monitoring of Astera Labs PT5161L series PCIe retimer chips.

This driver implementation originates from the CSDK available at [https://github.com/facebook/openbmc/tree/helium/common/recipes-lib/retimer-v2.14](<https://github.com/facebook/openbmc/tree/helium/common/recipes-lib/retimer-v2.14>) The communication protocol utilized is based on the I2C/SMBus standard.
