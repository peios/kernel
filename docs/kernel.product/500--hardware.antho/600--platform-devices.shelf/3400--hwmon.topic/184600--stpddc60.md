<a id="rst-description"></a>

## Description

This driver supports hardware monitoring for ST STPDDC60 controller chip and compatible modules.

The driver is a client driver to the core PMBus driver. Please see [Documentation/hwmon/pmbus.rst](~kernel/hardware/hwmon/pmbus) and Documentation.hwmon/pmbus-core for details on PMBus client drivers.

<a id="rst-usage-notes"></a>

## Usage Notes

This driver does not auto-detect devices. You will have to instantiate the devices explicitly. Please see [Documentation/i2c/instantiating-devices.rst](~kernel/hardware/i2c/instantiating-devices) for details.

The vout under- and over-voltage limits are set in relation to the commanded output voltage as a positive or negative offset in the interval 50mV to 400mV in 50mV steps. This means that the absolute values of the limits will change when the commanded output voltage changes. Also, care should be taken when writing to those limits since in the worst case the commanded output voltage could change at the same time as the limit is written to, which will lead to unpredictable results.

<a id="rst-platform-data-support"></a>

## Platform data support

The driver supports standard PMBus driver platform data.
