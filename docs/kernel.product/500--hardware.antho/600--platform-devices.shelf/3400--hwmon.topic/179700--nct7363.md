Author: Ban Feng &lt;[kcfeng0@nuvoton.com](<mailto:kcfeng0@nuvoton.com>)&gt;

<a id="rst-description"></a>

## Description

The NCT7363Y is a fan controller which provides up to 16 independent FAN input monitors, and up to 16 independent PWM outputs with SMBus interface.
