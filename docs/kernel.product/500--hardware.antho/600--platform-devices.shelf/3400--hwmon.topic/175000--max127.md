## Description

The MAX127 is a multirange, 12-bit data acquisition system (DAS) providing 8 analog input channels that are independently software programmable for a variety of ranges. The available ranges are \{0,5V\}, \{0,10V\}, \{-5,5V\} and \{-10,10V\}.

The MAX127 features a 2-wire, I2C-compatible serial interface that allows communication among multiple devices using SDA and SCL lines.
