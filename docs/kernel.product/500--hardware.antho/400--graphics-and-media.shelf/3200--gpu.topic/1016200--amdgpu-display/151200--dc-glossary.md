<a id="rst-dc-glossary"></a>

On this page, we try to keep track of acronyms related to the display component. If you do not find what you are looking for, look at the '[Documentation/gpu/amdgpu/amdgpu-glossary.rst](~kernel/hardware/gpu/amdgpu/amdgpu-glossary)'; if you cannot find it anywhere, consider asking on the amd-gfx mailing list and update this page.



- **<a id="rst-term-abm"></a>ABM**

  Adaptive Backlight Modulation

- **<a id="rst-term-apu"></a>APU**

  Accelerated Processing Unit

- **<a id="rst-term-asic"></a>ASIC**

  Application-Specific Integrated Circuit

- **<a id="rst-term-assr"></a>ASSR**

  Alternate Scrambler Seed Reset

- **<a id="rst-term-az"></a>AZ**

  Azalia (HD audio DMA engine)

- **<a id="rst-term-bpc"></a>BPC**

  Bits Per Colour/Component

- **<a id="rst-term-bpp"></a>BPP**

  Bits Per Pixel

- **<a id="rst-term-clocks"></a>Clocks**

  - PCLK: Pixel Clock

  - SYMCLK: Symbol Clock

  - SOCCLK: GPU Engine Clock

  - DISPCLK: Display Clock

  - DPPCLK: DPP Clock

  - DCFCLK: Display Controller Fabric Clock

  - REFCLK: Real Time Reference Clock

  - PPLL: Pixel PLL

  - FCLK: Fabric Clock

  - MCLK: Memory Clock

- **<a id="rst-term-crc"></a>CRC**

  Cyclic Redundancy Check

- **<a id="rst-term-crtc"></a>CRTC**

  Cathode Ray Tube Controller - commonly called "Controller" - Generates raw stream of pixels, clocked at pixel clock

- **<a id="rst-term-cvt"></a>CVT**

  Coordinated Video Timings

- **<a id="rst-term-dal"></a>DAL**

  Display Abstraction layer

- **<a id="rst-term-dc-software"></a>DC (Software)**

  Display Core

- **<a id="rst-term-dc-hardware"></a>DC (Hardware)**

  Display Controller

- **<a id="rst-term-dcc"></a>DCC**

  Delta Colour Compression

- **<a id="rst-term-dce"></a>DCE**

  Display Controller Engine

- **<a id="rst-term-dchub"></a>DCHUB**

  Display Controller HUB

- **<a id="rst-term-arb"></a>ARB**

  Arbiter

- **<a id="rst-term-vtg"></a>VTG**

  Vertical Timing Generator

- **<a id="rst-term-dcn"></a>DCN**

  Display Core Next

- **<a id="rst-term-dccg"></a>DCCG**

  Display Clock Generator block

- **<a id="rst-term-ddc"></a>DDC**

  Display Data Channel

- **<a id="rst-term-dio"></a>DIO**

  Display IO

- **<a id="rst-term-dpp"></a>DPP**

  Display Pipes and Planes

- **<a id="rst-term-dsc"></a>DSC**

  Display Stream Compression (Reduce the amount of bits to represent pixel count while at the same pixel clock)

- **<a id="rst-term-dgpu"></a>dGPU**

  discrete GPU

- **<a id="rst-term-dmif"></a>DMIF**

  Display Memory Interface

- **<a id="rst-term-dml"></a>DML**

  Display Mode Library

- **<a id="rst-term-dmcu"></a>DMCU**

  Display Micro-Controller Unit

- **<a id="rst-term-dmcub"></a>DMCUB**

  Display Micro-Controller Unit, version B

- **<a id="rst-term-dpcd"></a>DPCD**

  DisplayPort Configuration Data

- **<a id="rst-term-dpm-s"></a>DPM(S)**

  Display Power Management (Signaling)

- **<a id="rst-term-drr"></a>DRR**

  Dynamic Refresh Rate

- **<a id="rst-term-dwb"></a>DWB**

  Display Writeback

- **<a id="rst-term-fb"></a>FB**

  Frame Buffer

- **<a id="rst-term-fbc"></a>FBC**

  Frame Buffer Compression

- **<a id="rst-term-fec"></a>FEC**

  Forward Error Correction

- **<a id="rst-term-frl"></a>FRL**

  Fixed Rate Link

- **<a id="rst-term-gco"></a>GCO**

  Graphical Controller Object

- **<a id="rst-term-gsl"></a>GSL**

  Global Swap Lock

- **<a id="rst-term-igpu"></a>iGPU**

  integrated GPU

- **<a id="rst-term-isr"></a>ISR**

  Interrupt Service Request

- **<a id="rst-term-isv"></a>ISV**

  Independent Software Vendor

- **<a id="rst-term-kmd"></a>KMD**

  Kernel Mode Driver

- **<a id="rst-term-lb"></a>LB**

  Line Buffer

- **<a id="rst-term-lfc"></a>LFC**

  Low Framerate Compensation

- **<a id="rst-term-lttpr"></a>LTTPR**

  Link Training Tunable Phy Repeater

- **<a id="rst-term-lut"></a>LUT**

  Lookup Table

- **<a id="rst-term-mall"></a>MALL**

  Memory Access at Last Level

- **<a id="rst-term-mpc-mpcc"></a>MPC/MPCC**

  Multiple pipes and plane combine

- **<a id="rst-term-mpo"></a>MPO**

  Multi Plane Overlay

- **<a id="rst-term-mst"></a>MST**

  Multi Stream Transport

- **<a id="rst-term-nbp-state"></a>NBP State**

  Northbridge Power State

- **<a id="rst-term-nbio"></a>NBIO**

  North Bridge Input/Output

- **<a id="rst-term-odm"></a>ODM**

  Output Data Mapping

- **<a id="rst-term-opm"></a>OPM**

  Output Protection Manager

- **<a id="rst-term-opp"></a>OPP**

  Output Plane Processor

- **<a id="rst-term-optc"></a>OPTC**

  Output Pipe Timing Combiner

- **<a id="rst-term-otg"></a>OTG**

  Output Timing Generator

- **<a id="rst-term-pcon"></a>PCON**

  Power Controller

- **<a id="rst-term-pgfsm"></a>PGFSM**

  Power Gate Finite State Machine

- **<a id="rst-term-psr"></a>PSR**

  Panel Self Refresh

- **<a id="rst-term-scl"></a>SCL**

  Scaler

- **<a id="rst-term-sdp"></a>SDP**

  Scalable Data Port

- **<a id="rst-term-sls"></a>SLS**

  Single Large Surface

- **<a id="rst-term-sst"></a>SST**

  Single Stream Transport

- **<a id="rst-term-tmds"></a>TMDS**

  Transition-Minimized Differential Signaling

- **<a id="rst-term-ttu"></a>TTU**

  Time to Underflow

- **<a id="rst-term-vrr"></a>VRR**

  Variable Refresh Rate
