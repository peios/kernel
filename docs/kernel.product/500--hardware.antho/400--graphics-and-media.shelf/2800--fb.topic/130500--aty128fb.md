<a id="rst-aty128fb-ati-rage128-framebuffer-driver"></a>

This is a driver for a graphic framebuffer for ATI Rage128 based devices on Intel and PPC boxes.

Advantages:

> - It provides a nice large console (128 cols + 48 lines with 1024x768) without using tiny, unreadable fonts.
>
> - You can run XF68_FBDev on top of /dev/fb0
>
> - Most important: boot logo :-)

Disadvantages:

> - graphic mode is slower than text mode... but you should not notice if you use same resolution as you used in textmode.
>
> - still experimental.

<a id="rst-how-to-use-it"></a>

## How to use it?

Switching modes is done using the  video=aty128fb:&lt;resolution&gt;... modedb boot parameter or using `fbset` program.

See [Documentation/fb/modedb.rst](~kernel/hardware/fb/modedb) for more information on modedb resolutions.

You should compile in both vgacon (to boot if you remove your Rage128 from box) and aty128fb (for graphics mode). You should not compile-in vesafb unless you have primary display on non-Rage128 VBE2.0 device (see [Documentation/fb/vesafb.rst](~kernel/hardware/fb/vesafb) for details).

<a id="rst-x11"></a>

## X11

XF68_FBDev should generally work fine, but it is non-accelerated. As of this document, 8 and 32bpp works fine.  There have been palette issues when switching from X to console and back to X.  You will have to restart X to fix this.

<a id="rst-configuration"></a>

## Configuration

You can pass kernel command line options to vesafb with `video=aty128fb:option1,option2:value2,option3` (multiple options should be separated by comma, values are separated from options by `:`). Accepted options:


<table>
<tbody>
<tr>
<td>


noaccel

</td>
<td>


do not use acceleration engine. It is default.

</td>
</tr>
<tr>
<td>


accel

</td>
<td>


use acceleration engine. Not finished.

</td>
</tr>
<tr>
<td>


vmode:x

</td>
<td>


chooses PowerMacintosh video mode &lt;x&gt;. Deprecated.

</td>
</tr>
<tr>
<td>


cmode:x

</td>
<td>


chooses PowerMacintosh colour mode &lt;x&gt;. Deprecated.

</td>
</tr>
<tr>
<td>


&lt;XxX@X&gt;

</td>
<td>


selects startup videomode. See modedb.txt for detailed explanation. Default is 640x480x8bpp.

</td>
</tr>
</tbody>
</table>
