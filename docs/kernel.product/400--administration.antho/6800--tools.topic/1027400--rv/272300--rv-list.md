## List available monitors

<!-- SPDX-License-Identifier: GPL-2.0 -->

**Manual section:** 1

<a id="rst-synopsis"></a>

## SYNOPSIS

**rv list** \[*OPTIONS*\]

<a id="rst-description"></a>

## DESCRIPTION

The **rv list** command prints all available monitors. These monitors can be enabled using the **rv mon** command.

<a id="rst-options"></a>

## OPTIONS

**-h**, **--help**

> Print help menu.
