<a id="rst-v4l2-cid-hdr-sensor-mode"></a>

## `V4L2_CID_HDR_SENSOR_MODE`

> Change the sensor HDR mode. A HDR picture is obtained by merging two captures of the same scene using two different exposure periods.


<table>
<tbody>
<tr>
<td>


HDR linearize

</td>
<td>


The merger outputs a long exposure capture as long as it is not saturated.

</td>
</tr>
<tr>
<td>


HDR subtraction

</td>
<td>


This involves subtracting the short exposure frame from the long exposure frame.

</td>
</tr>
<tr>
<td>


No HDR

</td>
<td>


This mode is used for standard dynamic range (SDR) exposures.

</td>
</tr>
</tbody>
</table>
