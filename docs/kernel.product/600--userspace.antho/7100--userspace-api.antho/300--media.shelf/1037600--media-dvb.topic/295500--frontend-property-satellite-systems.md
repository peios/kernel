## DVB-S delivery system

The following parameters are valid for DVB-S:

- [DTV_API_VERSION](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-api-version>)

- [DTV_DELIVERY_SYSTEM](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-delivery-system>)

- [DTV_TUNE](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-tune>)

- [DTV_CLEAR](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-clear>)

- [DTV_FREQUENCY](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-frequency>)

- [DTV_INVERSION](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-inversion>)

- [DTV_SYMBOL_RATE](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-symbol-rate>)

- [DTV_INNER_FEC](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-inner-fec>)

- [DTV_VOLTAGE](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-voltage>)

- [DTV_TONE](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-tone>)

In addition, the [DTV QoS statistics](<~kernel/userspace/userspace-api/media-dvb/frontend-stat-properties#rst-frontend-stat-properties>) are also valid.

Future implementations might add those two missing parameters:

- [DTV_DISEQC_MASTER](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-diseqc-master>)

- [DTV_DISEQC_SLAVE_REPLY](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-diseqc-slave-reply>)

## DVB-S2 delivery system

In addition to all parameters valid for DVB-S, DVB-S2 supports the following parameters:

- [DTV_MODULATION](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-modulation>)

- [DTV_PILOT](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-pilot>)

- [DTV_ROLLOFF](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-rolloff>)

- [DTV_STREAM_ID](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-stream-id>)

- [DTV_SCRAMBLING_SEQUENCE_INDEX](<~kernel/userspace/userspace-api/media-dvb/fe-property-parameters#rst-dtv-scrambling-sequence-index>)

In addition, the [DTV QoS statistics](<~kernel/userspace/userspace-api/media-dvb/frontend-stat-properties#rst-frontend-stat-properties>) are also valid.
