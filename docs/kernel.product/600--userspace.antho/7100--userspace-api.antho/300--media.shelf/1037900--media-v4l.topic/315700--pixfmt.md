The V4L2 API was primarily designed for devices exchanging image data with applications. The struct `v4l2_pix_format` and struct `v4l2_pix_format_mplane` structures define the format and layout of an image in memory. The former is used with the single-planar API, while the latter is used with the multi-planar version (see [Single- and multi-planar APIs](<~kernel/userspace/userspace-api/media-v4l/planar-apis#rst-planar-apis>)). Image formats are negotiated with the [VIDIOC_S_FMT](<~kernel/userspace/userspace-api/media-v4l/vidioc-g-fmt#rst-vidioc-g-fmt>) ioctl. (The explanations here focus on video capturing and output, for overlay frame buffer formats see also [VIDIOC_G_FBUF](<https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/Documentation/userspace-api/media/v4l/vidioc-g-fbuf.rst?id=9021cc14f7d98b4a1d2c932f52c5343d4d0f6b92>).)
