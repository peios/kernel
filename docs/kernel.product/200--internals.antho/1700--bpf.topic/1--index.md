This directory contains documentation for the BPF (Berkeley Packet Filter) facility, with a focus on the extended BPF version (eBPF).

This kernel side documentation is still work in progress. The Cilium project also maintains a [BPF and XDP Reference Guide](<https://docs.cilium.io/en/latest/bpf/>) that goes into great technical depth about the BPF Architecture.
